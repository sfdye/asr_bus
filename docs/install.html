Install (iPhone)

1
Get Scriptable (Free)
2
3
Open Scriptable → Paste
4

Rename the script to ASR Bus

5

Allow location: Settings → Privacy → Location → Scriptable → Always

6

Long-press lock screen → Customize → Add Scriptable widget → select ASR Bus

7

Tap the widget → set When Interacting to Run Script

Widget Parameter (optional)

auto or empty — nearest stop via GPS
asr — Avenue South Residence
outram6 — Outram Park Exit 6
outram7 — Outram Park Exit 7
harbourfront — Harbourfront Exit D
Note: The minutes countdown may sometimes appear stale on the lock screen. This is an iOS limitation — widgets refresh on a system-managed schedule. Tap the widget to get the latest timing.
